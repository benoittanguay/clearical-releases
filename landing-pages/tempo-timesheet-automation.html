Technical Integration Details

Developers care about how it works. Here's the technical breakdown.

// Clearical detects:

const detectJiraTickets = () => {
  // Browser tabs
  "PROJ-142: Fix authentication bug"

  // IDE file paths
  "feature/AUTH-142-sso-login"

  // Git branches & commits
  "git: [AUTH-142] Implement SSO"

  // Meeting titles
  "Sprint Planning - PROJ-143"

  // Slack threads
  "Discussion on PROJ-144"
}

// Syncs to Tempo:

await syncToTempo({
  worklog: {
    issueId: "AUTH-142",
    timeSpent: "2h 34m",
    started: "2026-01-18T09:15:00",
    description: "Implemented SSO login flow with OAuth2 integration"
  }
})

Detection Sources

  • IDE Activity: Detects Jira IDs in open files, file paths, and git branch names
  • Browser Context: Reads tab titles, Jira UI, and pull request pages
  • Git Integration: Parses commit messages and branch naming conventions
  • Calendar Events: Extracts ticket IDs from meeting titles and descriptions
  • Communication Tools: Identifies tickets in Slack threads and messages

Tempo API Sync

Direct integration via Tempo REST API. Supports both Tempo Cloud and Tempo Server instances. Worklog entries include accurate timestamps, AI-generated descriptions, and proper issue attribution.
